# AXEN AI Academy

A Progressive Web Application for learning AI Engineering and AI/ML engineering skills through hands-on interactive tools.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
